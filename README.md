# 😊 Mood Tracker

A modern Mood Tracker application built with **React** and **Vite**.

## 🌟 Features

- 😊 Select your current mood
- 📜 View mood history
- 📊 Interactive pie chart showing mood distribution
- 📈 Progress bars for mood statistics
- 💾 Data persistence using Local Storage
- 🌙 Modern Dark Mode UI
- 📱 Responsive design for desktop and mobile
- 🕒 Displays date, time, and time of day for each mood entry

## 🛠️ Technologies Used

- React
- Vite
- Chart.js
- React Chart.js 2
- CSS3
- Local Storage
